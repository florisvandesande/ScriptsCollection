# WhatsApp PopClip Extension

This folder contains a PopClip extension package:

- `WhatsApp.popclipext`

The extension shows for selected phone-like text, normalizes the number, and opens a new chat in WhatsApp using:

- `https://wa.me/<number>`

If your selected number is local (for example `06...`), it prefixes your PopClip option `Default country code` (default: `31`).

## Install

1. In Finder, open this folder.
2. Double-click `WhatsApp.popclipext`.
3. Confirm install in PopClip.
